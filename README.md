# 미식쉐드 모바일 웹 UI

피그마에서 전달된 화면을 모바일 웹에 맞춰 옮긴 HTML/CSS 프로젝트입니다.

로고는 별도로 전달된 `Layer_1.svg` 원본을 사용합니다. 프로필, SNS 로그인, 휴대폰 인증, 가입 완료, 홈 피드백 아이콘과 홈 배너도 전달된 피그마 SVG의 원본 자산을 사용합니다.

현재 단계에서는 백엔드 API를 연결하지 않았습니다. 입력창, 체크박스, 버튼은 화면 확인용이며 회원가입 단계 이동만 HTML 링크로 연결되어 있습니다.

## 화면

- `index.html`: 홈
- `login.html`: 로그인
- `signup-verify.html`: 회원가입 본인인증
- `signup-info.html`: 회원가입 정보입력
- `signup-complete.html`: 회원가입 완료

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다. 정적 서버로 확인하려면 아래 명령을 사용합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 추후 작업

백엔드 개발이 완료되면 노션 API 명세에 맞춰 이메일 인증, 회원가입, 로그인 기능을 JavaScript로 한 번에 연결합니다.
